# Recipe App

A recipe discovery web application built with React that allows users to search for meals, explore recipes, and view ingredients with their respective quantities.

## Features

- Search recipes by name
- Browse recipes with images
- View ingredient lists and measurements
- Dynamic recipe data fetching
- Clean and responsive user interface

## Tech Stack

- React
- JavaScript
- CSS Modules
- Spoonacular API

## Getting Started

### Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd recipe-app
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

## API Integration

This project uses the [Spoonacular API](https://spoonacular.com/food-api) to fetch recipe information, images, and ingredient data.

An API key is required to access the API.
